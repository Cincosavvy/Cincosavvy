# Marnier "Mar" Crockton

**OT/ICS security researcher · PhD candidate in Computer Science at Howard University**

I study how to defend the systems that run the physical world: industrial control systems, SCADA networks, and the operational technology behind power, water, and manufacturing. I also build things, from network security tooling to full-stack apps and a multi-agent AI assistant.

---

### 🔬 Research focus
- **OT/ICS security**: SCADA/ICS traffic analysis, industrial protocols, and anomaly detection for critical infrastructure
- **Software-defined networking for defense**: building and attacking SDN testbeds with Mininet, Ryu, and Kytos
- **Human factors in security operations**: literature review on XR technologies for tactical decision making under stress
